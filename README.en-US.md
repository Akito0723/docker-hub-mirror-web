

# docker-hub-mirror-web
Docker Hub Mirror Accelerator - Web Interface


## Requirements

You need to install [Node](https://nodejs.org/zh-cn/) and [Yarn](https://legacy.yarnpkg.com/en/docs/install) to install dependencies and build the project. You can verify the installation using the following commands.
Note: The following steps are for Ubuntu. Please adjust them accordingly for other systems. To help others troubleshoot, please open an issue if you encounter any problems.

```shell
node -v
v16.20.0

yarn -v
1.22.19
```

## Install
```shell
yarn install
```

## Usage
```shell
yarn serve
```
